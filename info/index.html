ウェブサイトの透明性に関する説明

2026-04-26 / カテゴリ：レポート

このページでは、本サイトで使用されている技術的な仕様を解説します。

生成AIについて

本サイトは次のような生成AIを用いてサイトの枠組みを作成しています。AIはHTML、CSSを生成するのみに用いられており、サイト内のブログ、日記等は人間の手でコンテンツを作成しています。

  • ChatGPT（サイトの枠組みを作るために使用）
  • GitHub Copilot（生成された枠組みの修正・調整のために使用）
  • Claude（生成された枠組みの修正・調整のために使用）
  • Gemini（ウェブアプリの一部に使用）

その他使用している技術

  • HTML
  • JavaScript
  • CSS

解析ツールの使用について

このサイトではFC2カウンターを用いてアクセス数解析を行っています。また、Google Search Consoleを用いてGoogle検索に対しインデックス登録を行っています。

このサイトをホストしているサービス

このサイトはGitHub Pagesの無料プランでホストされています。リポジトリは公開されています。
