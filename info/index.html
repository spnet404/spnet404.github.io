ウェブサイトの透明性に関する説明

2026-04-26 / カテゴリ：レポート

このページでは、本サイトで使用されている技術的な仕様を解説します。

生成AIについて

本サイトは次のような生成AIを用いてサイトの枠組みを作成しています。AIはHTML、CSSを生成するのみに用いられており、サイト内のブログ、日記等は人間の手でコンテンツを作成しています。

  • ChatGPT（サイトの枠組みを作るために使用）
  • GitHub Copilot（生成された枠組みの修正・調整のために使用）
  • Claude（生成された枠組みの修正・調整のために使用）
  • Gemini（ウェブアプリの一部に使用）

その他使用している技術

  • HTML
  • JavaScript
  • CSS
  • JSON
  • 埋め込みサービス「BlueskyTimeline」（免責事項後述）公式サイト

解析ツールの使用について

このサイトではFC2カウンターを用いてアクセス数解析を行っています。また、Google Search Console、Bing Webmaster Toolsを用いて各社検索エンジンに対しインデックス登録を行っています。

このサイトをホストしているサービス

このサイトはGitHub Pagesの無料プランでホストされています。リポジトリは公開されています。

埋め込みサービスの免責事項

このサイトでは、BlueSkyTimelineを用いてBlueSkyの投稿を埋め込んでいます。公式の記述によると、サービスの改善・分析のために、Google Analyticsを使用しているそうです。詳しくは公式ページをご確認ください。

AI学習・その他著作権について

本サイトはリンクフリーです。リンクを貼ってサイトを紹介する行為については制限しません。しかし、iframe等で他サイトに埋め込む形での転載はやめてください。

本サイトは様々な生成AIを使用してビルドしています。そのため、本サイトのAI学習を制限することはありません。しかし、私が書いたテキストコンテンツを模倣するなどはお控えください。
