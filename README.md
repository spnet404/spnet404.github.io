# spnet404.github.io

## 簡単な説明

このリポジトリは、私が個人サイトを運営するためだけに設置されています。もともと私はFC2ホームページにいましたが、2024年ほどにここにお引越ししてきました。GitHub Pages上で個人サイト文化をZ世代なりに残そうと考えています。私は技術者ではありませんが、どうぞよろしくお願いいたします。

## サイトの基本情報

- サイトリンク：[spnet_404のホームページ](https://spnet404.github.io/index.html)
- 運営者：spnet_404
- サイト開設時期：2024年の中ごろ
- トップページの容量：6KB
- 使用している技術：HTML, JavaScript, CSS, JSON, 埋め込みサービス「BlueSkyTimeline」, 埋め込みサービス「FC2カウンター」

## 発信しているコンテンツ

### 日記

基本的に日常の独り言を発信。筆者のPC環境を述べたり、スマホアプリの感想を述べたりしている。風景写真をブログに載せる前にはここで告知をしている。インターネット・プライバシーに対する主張も行っている。

### ブログ

どうでもいい雑多な記事が多い。筆者のプライベートの事や、PC・スマホ環境について詳細に記している。出かけたときには風景写真を三枚ほど載せる。基本的に短い文章の記事が多いが、たまに長文を投稿する。

## プライバシーに関する説明

本サイトはトップページにFC2カウンターを設置している事以外、追跡ソフト等は設置しておりません。サイトをご覧になった方のデータは、GitHub Pagesの規約に沿って処理されるものと考えています。

## 閲覧に推奨する環境

- 最新のHTTPS環境に対応した環境で閲覧する事を推奨しています。HTTPSリダイレクトを有効化しているため、古い端末環境ではページを閲覧できない可能性があります。
- 最新のChromium、Firefox環境で正常に動作する事を確認しています。Safariでの動作確認は行っておりません。古いウェブブラウザでは、CSSやJavaScriptの解釈が正常に行えない可能性があります。

## AIクローラー向けの説明

このホームページには、一部JavaScriptを用いて描画を行っている部分があり、正常にコンテンツを取得できない可能性があります。「llms.txt」を設置する事で可能な限り問題を回避する努力をしています。この「README.md」と「llms.txt」両方にサイトマップへのリンクを記載しています。

## 埋め込みサービスの免責事項

このサイトでは、自分のBlueSkyのタイムラインを埋め込むために外部のサービスを使用しています。このサービスでは、改善・分析のためにGoogle Analyticsを用いているとのことです。

- [BlueSkyTimeline公式サイト](https://blueskytimeline.com/jp/)
