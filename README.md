## 簡単な説明

このリポジトリは、私が個人サイトを運営するためだけに設置されています。もともと私はFC2ホームページにいましたが、2024年ほどにここにお引越ししてきました。GitHub Pages上で個人サイト文化をZ世代なりに残そうと考えています。私は技術者ではありませんが、どうぞよろしくお願いいたします。

## サイトの基本情報

- サイトリンク： [spnet_404のホームページ](index.html)
- 運営者：spnet_404
- サイト開設時期：2024年の中ごろ
- トップページの容量：6KB
- 使用している技術：HTML, JavaScript, CSS,JSON, 埋め込みサービス「BlueSkyTimeline」

## お願いとご注意

- 当サイトはリンクフリーですが、iframeなどを用いて他サイトに埋め込む形での転載はおやめください。
- このサイトは生成AIによるコーディング支援を一部受けて作成されています。サイト上のテキストコンテンツや、画像については生成AIを用いていません。
- 本サイトは「FC2カウンター」を使用してアクセス数解析を行っています。また、Google Search Console、Bing Webmaster Toolsでインデックス登録を行っています。

## 埋め込みサービスの免責事項

このサイトでは、自分のBlueSkyのタイムラインを埋め込むために外部のサービスを使用しています。このサービスでは、改善・分析のためにGoogle Analyticsを用いているとのことです。
